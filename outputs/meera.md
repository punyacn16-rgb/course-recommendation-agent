# Learning Path for Meera

**Background:** Self-taught HTML/CSS hobbyist who has never used JavaScript.
**Goal:** Become a full-stack web developer able to build and deploy complete web applications.
**Known skills:** html, css

## Recommended Path

### 1. SQL Fundamentals  _( prerequisite, ~12h )_
- **Skills taught:** sql
- **Why:** Teaches sql; this course is a prerequisite needed before later courses in this path.

### 2. Database Design & Modeling  _( 🎯 goal course, ~14h )_
- **Skills taught:** db-design
- **Why:** Teaches db-design building on SQL Fundamentals; this course directly supports the goal: "Become a full-stack web developer able to build and deploy complete web applications.".

### 3. JavaScript Fundamentals  _( 🎯 goal course, ~18h )_
- **Skills taught:** javascript
- **Why:** Teaches javascript; this course directly supports the goal: "Become a full-stack web developer able to build and deploy complete web applications.".

### 4. Backend Development with Node.js  _( 🎯 goal course, ~20h )_
- **Skills taught:** nodejs, rest-apis
- **Why:** Teaches nodejs, rest-apis building on JavaScript Fundamentals; this course directly supports the goal: "Become a full-stack web developer able to build and deploy complete web applications.".
