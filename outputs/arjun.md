# Learning Path for Arjun

**Background:** Final-year CS student who has completed an intro Python course and knows basic SQL.
**Goal:** Break into machine learning and eventually specialize in natural language processing.
**Known skills:** python, programming-basics, sql

## Recommended Path

### 1. Data Analysis with Pandas  _( prerequisite, ~15h )_
- **Skills taught:** pandas, data-analysis
- **Why:** Teaches pandas, data-analysis; this course is a prerequisite needed before later courses in this path.

### 2. Statistics & Probability for Data Science  _( prerequisite, ~16h )_
- **Skills taught:** statistics, probability
- **Why:** Teaches statistics, probability; this course is a prerequisite needed before later courses in this path.

### 3. Intermediate Python (OOP & File Handling)  _( 🎯 goal course, ~18h )_
- **Skills taught:** python-oop, file-handling
- **Why:** Teaches python-oop, file-handling; this course directly supports the goal: "Break into machine learning and eventually specialize in natural language processing.".

### 4. Machine Learning Foundations  _( 🎯 goal course, ~30h )_
- **Skills taught:** ml-basics, scikit-learn
- **Why:** Teaches ml-basics, scikit-learn building on Data Analysis with Pandas, Statistics & Probability for Data Science, Intermediate Python (OOP & File Handling); this course directly supports the goal: "Break into machine learning and eventually specialize in natural language processing.".

### 5. Deep Learning with PyTorch  _( 🎯 goal course, ~35h )_
- **Skills taught:** deep-learning, pytorch
- **Why:** Teaches deep-learning, pytorch building on Machine Learning Foundations; this course directly supports the goal: "Break into machine learning and eventually specialize in natural language processing.".
